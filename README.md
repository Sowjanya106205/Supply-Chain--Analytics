# Supply Chain Analytics

## Project Overview

Supply Chain Analytics is a data analytics project developed to analyze supply chain sales, profit, orders, products, markets, shipping modes, categories, and delivery performance.

The project uses Python for data understanding and preprocessing, SQL for data analysis, and Power BI for interactive visualization and dashboard creation.

## Technologies Used

- Python
- Pandas
- SQL
- MySQL
- Power BI
- Jupyter Notebook

## Project Workflow

Dataset  
→ Python Data Understanding & Preprocessing  
→ SQL Analysis  
→ Power BI Visualization  
→ Business Insights

## Dataset

The project uses the DataCo Supply Chain dataset.

The dataset contains supply-chain-related information such as:

- Sales
- Order Profit
- Market
- Order Region
- Product
- Category
- Shipping Mode
- Order Status
- Delivery information

## Python

Python was used for:

- Data loading
- Data understanding
- Data cleaning
- Missing-value checking
- Date processing
- Feature engineering
- Creating delivery-related features
- Preparing the final dataset

The Python notebook is available in:

`01_Data_Understanding.ipynb`

## SQL Analysis

SQL was used to analyze:

- Total sales
- Total profit
- Sales by market
- Profit by market
- Sales by shipping mode
- Orders by shipping mode
- Top products by sales
- Top products by profit
- Sales by category
- Profit by category
- Sales by order region
- Profit by order region
- Market profit margin
- Average sales per order
- Average profit per order
- Top countries by sales

SQL queries are available in:

`SQL/DataCoSupplyChainDataset_Final.sql`

## Power BI

Power BI was used to create interactive visualizations and dashboards for analyzing the supply chain data.

The dashboard helps users understand:

- Sales performance
- Profit performance
- Market performance
- Product performance
- Category performance
- Shipping performance
- Order performance
- Delivery performance

Power BI file:

`supplychain.pbix`

## Key Outcomes

The project provides an analytical view of supply chain operations and helps identify important patterns in sales, profitability, products, markets, shipping modes, and orders.
